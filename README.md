# IP Logger Ruby 🌐

Aplicação simples feita em Ruby com Sinatra.

## Funcionalidades

* Mostra o IP do visitante
* Identifica o navegador
* Registra a hora do acesso
* Exibe as informações no terminal

## Instalação

```bash
gem install sinatra
```

## Como usar

```bash
ruby app.rb
```

Acesse:

```text
http://localhost:8080
```

## Tecnologias

* Ruby
* Sinatra
